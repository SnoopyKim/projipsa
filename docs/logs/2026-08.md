## [2026-08-03] update | Purpose restated and documentation restructured

- found: a README review compared the README against the shipped tree, both
  manifests, the three shared workflows, and this memory tree
- restated: the Maker corrected the project's purpose. Projipsa exists so that
  project understanding survives the session and substantial work can be
  delegated against it; the memory is the durable shared state that delegated
  work runs on. Cross-host support is a distribution constraint that follows,
  not the goal. `wiki/project/overview.md` had recorded the constraint as the
  purpose, which is the framing the README inherited
- recorded: the design lineage the Maker named — the LLM-wiki pattern for the
  memory layer, and agent loop and multi-node agent graph design for the
  delivery layer, where Projipsa's contribution is where the shared state lives
  after the run ends. Cited by URL rather than copied, per the public-root rule
- changed: `README.md` rewritten around purpose, install, and usage. Install
  moved from 83% down the page to the top, the plugin version is stated, and a
  five-minute onboarding walkthrough was added
- added: `CONTRIBUTING.md` now holds repository layout, adapter structure, the
  validators, and the publishing checklist
- removed: the v0.3 invocation migration table, which addressed a migration
  from a version that was never listed in a marketplace
- fixed: three README claims that had drifted. It asserted that
  `validate_memory.py` rejects a pointer block naming a different root, which
  [open questions](../wiki/questions/open-questions.md) records as a reproduced
  defect; it described the package validator's scan as the shipped tree and

  never documented why neither host may use a `skills/` directory
- removed: both vocabulary checks in `scripts/validate_package.py` — a

  expression, while none of the drifted claims above were covered by any check.
  The Maker's standing constraint is that the package validator carries no
  semantic or vocabulary rules; documentation carries the concept
